# MAHIRA COMUNICATION website

This is a static HTML, CSS and JavaScript website. GitHub Pages deploys it directly; no build command is required.

## Publish with GitHub Pages

1. Create a new repository on GitHub. A public repository is the simplest option.
2. Install and sign in to GitHub Desktop, then clone the new repository.
3. Copy the contents of this website folder into the cloned repository. Keep `index.html` at the repository root and preserve the `images` and `assets` folders.
4. In GitHub Desktop, commit the files to the `main` branch and push them to GitHub.
5. On GitHub, open the repository's **Settings → Pages** and set the build and deployment source to **GitHub Actions**.
6. Open the **Actions** tab and wait for **Deploy static site to GitHub Pages** to complete. The published address will be shown in the workflow run and under **Settings → Pages**. For a project repository, it is usually `https://<github-username>.github.io/<repository-name>/`.

Future commits pushed to `main` will automatically redeploy the site.
